## Official syllabus

> ER-model, relational model: relational algebra, tuple calculus, SQL, integrity constraints, normal form, file organization, indexing, data types, data transformation such as normalization, discretization, sampling, compression; data warehouse modelling: schema for multidimensional data models, concept hierarchies, measures: categorization and computations.

## Topic plan

Topic pages will be written in this order, following the [notes playbook](https://github.com/ashyou09/Gate-da/blob/main/NOTES_PLAYBOOK.md). Each one gets a topic map, teaching from basics, a summary, solved PYQs and predicted 2027 questions.

1. ER model & relational model, keys, integrity constraints <span class="tag high">★ HIGH</span>
2. Functional dependencies, closures & normal forms <span class="tag high">★ HIGH</span>
3. Relational algebra & tuple calculus <span class="tag med">◆ MED</span>
4. SQL: joins, GROUP BY / HAVING, nested queries <span class="tag high">★ HIGH</span>
5. File organization & indexing, B+ trees <span class="tag med">◆ MED</span>
6. Data types & data transformation (normalization, discretization, sampling, compression) <span class="tag med">◆ MED</span>
7. Data warehousing: star/snowflake schema, OLAP, concept hierarchies, measures <span class="tag med">◆ MED</span>
