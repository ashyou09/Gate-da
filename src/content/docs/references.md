## Community resource collection

### PDSA picks from that list

- **NPTEL: [Programming, Data Structures and Algorithms using Python](https://nptel.ac.in/courses/106106145)** by Madhav Mukund. Covers the whole PDSA syllabus in Python, the language GATE DA uses.
- **Book:** *Data Structures & Algorithms in Python* (Goodrich, Tamassia, Goldwasser).
- **Book:** *Algorithm Design*, Kleinberg & Tardos.
- **Cheatsheet:** [Princeton algs4 cheatsheet](https://algs4.cs.princeton.edu/cheatsheet/) for complexity tables.
