- 2024 Q43: when are two ReLU networks equivalent?
- 2025 Q42: backprop gradients through ReLU;
- 2025 Q48: continuity and differentiability of ReLU;
- 2026 Q56: counting MLP parameters.

None of them needed heavy theory. Each needed **one forward pass, one chain rule, or one count**, done carefully.

## Topic map

<div class="mindmap">

- **Neural networks**
  - Neuron
    - $z = w^\top x + b$, $a = g(z)$
  - Activations
    - sigmoid, tanh, ReLU, leaky ReLU, softmax
    - without non-linearity, any depth collapses to one linear map
  - MLP
    - layers, fully connected, feed-forward
    - forward pass layer by layer
    - parameters $= \sum (n_{\text{in}} + 1)\,n_{\text{out}}$
  - Training
    - loss: MSE / cross-entropy
    - backprop = chain rule, reusing upstream gradients
    - ReLU passes gradient only where $z > 0$
  - Issues
    - vanishing gradients (sigmoid), dead ReLUs
    - symmetric initialisation, overfitting → dropout, weight decay

</div>

## 10.1 The neuron

A single artificial neuron takes inputs $x_1, \dots, x_d$, computes a **weighted sum plus bias**, then applies an **activation function** $g$:

$$
z = w^\top x + b, \qquad a = g(z).
$$

With $g = \text{sign}$, this is the perceptron (topic 4). With $g = \sigma$, it's logistic regression. A neural network is many of these neurons, wired in **layers**.

### Why non-linearity is essential

If every activation were linear, then

$$
W_2(W_1x + b_1) + b_2 = (W_2W_1)x + (W_2b_1 + b_2),
$$

which is **one** linear map. However many layers you stack, a network of linear units can only draw a linear boundary, and it can't solve XOR. Non-linear activations between the layers are what let deep networks represent curved boundaries.

**Universal approximation theorem:** one hidden layer with enough non-linear units can approximate any continuous function on a bounded region as closely as you like. Depth makes many functions far more **efficient** to represent.

## 10.3 The multi-layer perceptron (feed-forward network)

Layers are applied one after another. Every unit in a layer connects to every unit in the next layer (**fully connected**), and information flows only forward, with no cycles.

$$
h^{(1)} = g\big(W^{(1)}x + b^{(1)}\big), \quad h^{(2)} = g\big(W^{(2)}h^{(1)} + b^{(2)}\big), \quad \dots, \quad \hat y = \text{output}\big(W^{(L)}h^{(L-1)} + b^{(L)}\big).
$$

$W^{(l)}$ has shape $(n_l \times n_{l-1})$: **rows = units in this layer, columns = units in the previous layer**.

### Counting parameters

<div class="formula">

$$
\#\text{params} = \sum_{l=1}^{L}\big(n_{l-1}\cdot n_l + n_l\big) = \sum_{l}(n_{l-1} + 1)\,n_l \qquad (\text{drop the } +n_l \text{ if there are no biases})
$$

The input layer has **no** parameters. It just holds the features.

## 10.4 The forward pass, by hand

Inputs $x = (1, 2)$. Hidden layer: $W^{(1)} = \begin{pmatrix}1 & -1\\ 2 & 1\end{pmatrix}$, $b^{(1)} = (0, -1)$, ReLU. Output: $w^{(2)} = (2, 1)$, $b^{(2)} = 0.5$, linear.

1. $z^{(1)} = W^{(1)}x + b^{(1)} = (1 - 2 + 0,\; 2 + 2 - 1) = (-1, 3)$
2. $h = \text{ReLU}(z^{(1)}) = (0, 3)$. The first unit is **inactive**.
3. $\hat y = 2(0) + 1(3) + 0.5 = $ **3.5**

**Write the pre-activation $z$ before applying ReLU.** Whether $z > 0$ decides both the output and, later, whether any gradient flows back through that unit.

### A shortcut: ReLU networks on known-sign inputs

If you know every ReLU's input is positive (for example, all inputs and weights are positive), every ReLU acts as the identity. The network is then **linear**, and the coefficient of $x_i$ in the output is

$$
\sum_{\text{paths } x_i \to \text{output}} \;\prod_{\text{edges on the path}} w.
$$

That's exactly 2024 Q43.

## 10.5 Training: loss + gradient descent

Choose a loss: **MSE** for regression, **cross-entropy** (with sigmoid or softmax outputs) for classification. Minimise it by gradient descent (topic 2): $W \leftarrow W - \eta\,\partial L/\partial W$. The loss of a network is **non-convex**, so GD finds a good local minimum rather than a guaranteed global one.

## 10.6 Backpropagation = the chain rule, organised

To get $\partial L/\partial w$ for a weight deep inside the network, multiply the local derivatives **along the path** from that weight to the loss:

<div class="formula">

For a weight $w_{ji}$ feeding unit $j$ (pre-activation $z_j$, activation $a_j = g(z_j)$) from input $a_i$:

$$
\frac{\partial L}{\partial w_{ji}} = \underbrace{\frac{\partial L}{\partial z_j}}_{\delta_j}\cdot\frac{\partial z_j}{\partial w_{ji}} = \delta_j\,a_i,
\qquad
\delta_j = g'(z_j)\sum_{k \in \text{next layer}} w_{kj}\,\delta_k.
$$

- **Gradient of a weight = (error signal at its output unit) × (activation at its input).**
- The $\delta$ values are computed **backwards**, from the output layer to the input layer, reusing each layer's $\delta$ for the layer before it. That reuse is why backprop costs about as much as one forward pass.
- For ReLU, $g'(z_j) = 0$ when $z_j < 0$. **An inactive unit blocks all gradient through it.**
- Sigmoid output with cross-entropy, or linear output with MSE: the output $\delta = \hat y - y$ (up to a constant factor).

</div>

## 10.7 Things that go wrong in training

- **Vanishing gradients:** backprop multiplies one $g'$ per layer. With sigmoid, each factor is at most 0.25, so after 5 layers the factor is at most $0.25^5 \approx 0.001$, and the early layers barely learn. ReLU (slope 1) helps.
- **Dead ReLUs:** a unit whose $z < 0$ for every input gets zero gradient forever. Leaky ReLU helps.
- **Symmetric initialisation:** if all the weights start equal, every hidden unit computes the same thing and gets the same update, and they stay identical forever. Initialise weights **randomly**.
- **Overfitting:** networks have many parameters. Use **dropout** (randomly zero units during training), **weight decay** (L2, topic 3), **early stopping** (watch the validation error, topic 1) and more data.

## Summary: important points

<div class="formula">

1. Neuron: $a = g(w^\top x + b)$. An MLP stacks fully connected layers, feeding forward only.
2. Without non-linear activations, any depth reduces to one linear map, which can't solve XOR.
3. $\sigma' = \sigma(1 - \sigma) \le 0.25$, $\tanh' = 1 - \tanh^2 \le 1$. ReLU' is 0 or 1. ReLU is continuous, but not differentiable at 0.
4. Parameters $= \sum(n_{l-1} + 1)n_l$, or $\sum n_{l-1}n_l$ without biases. The input layer has none.
5. Forward pass: compute $z$, then $g(z)$, layer by layer. Note which ReLUs are inactive ($z < 0$).
6. Backprop: $\partial L/\partial w_{ji} = \delta_j a_i$, with $\delta_j = g'(z_j)\sum_k w_{kj}\delta_k$. An inactive ReLU passes zero gradient.
7. With every ReLU active, the network is linear and each coefficient is a sum of path products.
8. Sigmoid causes vanishing gradients. Initialise weights randomly. Regularise with dropout, weight decay and early stopping.

</div>

<div class="trap">

- Count **weights between layers**, not neurons. Add biases only if the question includes them.
- $\text{ReLU}(ax) = a\,\text{ReLU}(x)$ only for $a \ge 0$.
- A unit with $z < 0$ has zero gradient through it, even if its weight is large.
- "Differentiable everywhere" is false for ReLU. "Continuous everywhere" is true.

</div>

### GATE DA 2025 Q42 (2 marks, MCQ)

$u$ and $v$ feed two ReLU units: top $= R(au + bv)$, bottom $= R(cu + dv)$. They feed the output $y = R(e \cdot \text{top} + f \cdot \text{bottom})$. With $u = 2$, $v = 3$, $a = b = c = 1$, $d = -1$, $e = 4$, $f = -1$, which is correct?
(A) $\partial y/\partial a = 8$, $\partial y/\partial f = 0$ (B) $1, 0$ (C) $1, -1$ (D) $2, -1$

<details>
<summary>Show solution</summary>

**Answer: (A)**

**Forward pass:**
- top: $z = 2 + 3 = 5$, so $h_1 = 5$.
- bottom: $z = 2 - 3 = -1$, so $h_2 = 0$ (inactive).
- output: $z = 4(5) - 1(0) = 20$, so $y = 20$.

**Backward pass:**
- $\dfrac{\partial y}{\partial a} = R'(20)\cdot e\cdot R'(5)\cdot u = 1 \cdot 4 \cdot 1 \cdot 2 = 8$.
- $\dfrac{\partial y}{\partial f} = R'(20)\cdot h_2 = 1 \cdot 0 = 0$.

</details>

### GATE DA 2025 Q48 (2 marks, MSQ)

Which statements about ReLU$(x) = \max(x, 0)$ are correct?
(A) ReLU is continuous everywhere (B) ReLU is differentiable everywhere (C) ReLU is not differentiable at $x = 0$ (D) ReLU$(x)$ = ReLU$(ax)$ for all $a \in \mathbb{R}$

<details>
<summary>Show solution</summary>

**Answer: A; C**

There's no jump, so ReLU is continuous. At 0, the left derivative is 0 and the right derivative is 1, so it isn't differentiable there.

(D) is false. For example, $a = -1$, $x = 1$: ReLU(1) = 1 but ReLU(−1) = 0. Even for positive $a \ne 1$, $\text{ReLU}(ax) = a\,\text{ReLU}(x) \ne \text{ReLU}(x)$.

</details>

### GATE DA 2024 Q43 (2 marks, MCQ)

Figure 1 is a ReLU network with zero biases. $x_1$ connects to all three first-layer units, and $x_2$ and $x_3$ each connect to two of them, all with weight 1. Each first-layer unit connects to both second-layer units with weight 2, and both connect to the output with weight 3. Figure 2 is a single unit $px_1 + qx_2 + rx_3$. For positive inputs, which $(p, q, r)$ makes them equivalent?
(A) 36, 24, 24 (B) 24, 24, 36 (C) 18, 36, 24 (D) 36, 36, 36

<details>
<summary>Show solution</summary>

**Answer: (A)**

All inputs and weights are positive, so every ReLU is active and the network is linear (§10.4). Each path's weight product is $1 \times 2 \times 3 = 6$.

- $x_1$: 3 first-layer units × 2 second-layer units = 6 paths, so $6 \times 6 = 36$.
- $x_2$: 2 × 2 = 4 paths, so $24$.
- $x_3$: 4 paths, so $24$.

(D) is the trap for anyone who assumes every input connects to every first-layer unit.

</details>
